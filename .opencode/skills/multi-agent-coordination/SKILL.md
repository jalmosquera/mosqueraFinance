# Multi-Agent Coordination

Read `docs/agent-workflow.md` before delegating.

Assign independent work in parallel only when files and contracts do not overlap. Assign one writable owner per file. Have Architect, Finance, and Security review cross-domain changes before implementation. Require each agent to report scope, files, verification, risks, and handoff.

The orchestrator alone integrates cross-agent work and runs integration checks. Do not authorize deployment, push, merge, public exposure, or destructive operations without the user.
