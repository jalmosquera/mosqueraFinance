## Projection Reference Decision

There is no exact original containing the requested in-app `Resumen / Detalle /
Proyección` segmented selector. The closest projection composition is
`FEDFDBFC-C901-43A5-B50A-4F7678CDCAE8.png`; the implementation uses its card
proportions and orange-wave treatment, while the app header and bottom navigation
follow the iPhone references above. No original is used as a screen background.
